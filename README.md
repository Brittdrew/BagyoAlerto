# BagyoAlerto

BagyoAlerto is a comprehensive typhoon monitoring and evacuation center management application designed for local communities.

## Repository Structure

This repository is organized as a monorepo containing both the frontend and backend services:

- **[bagyo-alerto-frontend](./bagyo-alerto-frontend)**: A React/Vite-based single page application offering a real-time dashboard, interactive evacuation center map, local weather alerts, and typhoon forecasts.
- **[bagyo-alerto-backend](./bagyo-alerto-backend)**: A Laravel-based REST API serving evacuation center details, barangay populations, active recommendations, and typhoon logs.
